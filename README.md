# 文献阅读系统 · 第二题作业

社科院研究生期末作业 · 第二题（50 分）。本仓库是一套可复用的文献阅读流程：三个 Skill 负责「检索—精读—归档」，一个研究边际 Agent 负责「判断还有哪一块值得做」，同一研究问题跑两轮，第二轮专门寻找最可能推翻第一轮判断的证据。

## 研究问题

**算力基础设施部署如何改变企业创新质量在企业之间的分布？**

已有研究分两层。**数量层**：谷城等（2026）以国家超算中心设立为冲击，识别算力供给对专利申请数量的效应，并用同城企业专利申请数的变异系数检验「创新鸿沟」；王倩等（2026）发现智能算力部署促进企业跨区域技术合作。**质量层**：徐振华（2026）与张纪录（2026）以绿色口径、余明桂等（2026）以 AI 口径、谢璇等（2026）以数字技术专利**被引次数总量**为口径，分别报告算力提升了创新质量；其中谢璇等还以营业收入中位数二分，比较了大企业与小企业的质量效应差异。

两层合起来给出一个明确的空白：**质量一侧从未被当作离散程度来测**。具体分四层看，前三层都有人做过——

| 层 | 是否已做 | 代表 |
|---|---|---|
| 质量均值 | 已做 | 徐振华、张纪录、余明桂（知识宽度）、谢璇（被引总量） |
| 质量构成占比（策略性 vs 实质性） | 已做，限绿色口径 | 软科学 2026-04、管理学报 2024-07 |
| 质量按规模的分组均值差异 | 已做 | 谢璇 |
| 质量的企业间**离散度** | **未做** | —— |

五种质量度量（发明专利占比、绿色创新质量、绿色量质并置、AI 专利知识宽度、数字技术专利被引总量）没有一种报告过企业间的离散度、分位差或基尼系数；唯一的分布度量（变异系数）落在数量上。

本研究的边际因此不是「研究质量」，也不是「检验企业间质量差异」，而是**「把质量差距当作连续分布统计量来估计」**：在同一政策情境与同一数据窗口下，把谷城的变异系数检验从数量口径换成质量口径，并把两组结果并列，检验「数量差距收敛」与「质量差距收敛」是否同向。

> 第一轮提出该方向（`rounds/round1/memo-1.md` 第 6 节），第二轮补检后**收窄并保留**（`rounds/round2/memo-2.md` 第 4 节）。收窄要点：同时报告均值与分布、质量口径用两个指标、锁定 2007–2023 与谷城（2026）可比。质量指标最终定为「发明专利占比（比率）」与「专利知识宽度（复杂度）」，不再用被引总量——后者与数量高度相关，且谢璇（2026）已用。
>
> **三次边界更正，均因读到了更多文献**。
>
> 第一次（11-26 23:40）：补录余明桂等（2026，《经济研究》第 8 期），「尚未回答质量是否提升」不再成立——非绿色口径的质量均值已有顶刊工作，表述改为「均值已做、分布未做」。
>
> 第二次（11-27 00:50）：召回补正核查捞出谢璇等（2026，《经济与管理研究》47(7)），与谷城同政策、同样本、同方法，且报告「大企业数量、小企业质量」的异质性——**按规模分组的质量差异也被做掉了**，表述收窄为「分组均值已做、连续分布未做」。
>
> 第三次（11-27 00:26）：余明桂全文核对（无分布度量，威胁解除）与 Q2 的 208 条全量复核（时间切片，去重后 208、零重复）同时完成，从中又捞出 2 篇做**质量构成占比**的（软科学 2026-04「从策略性向实质性的结构性矫正」、管理学报 2024-07「实质性绿色创新偏好」）。表述最终收窄为「**质量的企业间离散度未做**」——不是「质量的分布」，因为构成占比也属于分布家族。
>
> 两处漏检的原因不同：余明桂是关键词不含「创新质量」；谢璇是主题词用「数字技术创新」而非「创新」，落在检索式词面之外。核查过程见 `rounds/round2/recall-check.md`，归档见 `vault/10-论文笔记/` 序号 7、8（均为仅摘要）。

**入选标准**：2021–2026 年；CSSCI 或北大核心；题名或摘要同时涉及「算力 / 超算 / 数据中心」与「创新 / 专利 / 研发」；同一论文的工作稿与期刊版计一篇。

## 调用方式

本项目采用**「按 README 顺序逐份读取并执行」**，不依赖工作台把项目内 Skill 注册为原生命令。原因：三个 `SKILL.md` 位于项目目录而非工作台的全局技能目录，工作台不会自动发现它们；逐份读取可保证教师在任何支持文件读取的工作台中复现。

一次完整调用按下列顺序，每一步的输出即下一步的输入：

```
README.md §研究问题
  → skills/search/SKILL.md      → rounds/roundN/search-log.md + cnki-raw.json
  → skills/read/SKILL.md        → materials/*.md + vault/10-论文笔记/*.md
  → skills/archive/SKILL.md     → vault/00-索引/*、vault/20-主题笔记/*、archive-check.md
  → agents/research-margin.md   → rounds/roundN/memo-N.md
  → 本人回查                     → rounds/round2/verification.md
```

可直接粘贴的启动请求：

> 请读取 `README.md` 与研究问题，按「调用方式」一节的顺序依次读取并执行 `skills/search/SKILL.md`、`skills/read/SKILL.md`、`skills/archive/SKILL.md` 与 `agents/research-margin.md`，保存本轮检索记录、论文笔记、归档索引与第一轮备忘录，列出全部产物路径，完成后停止等待检查。

第二轮请求：

> 请读取 `README.md` 与 `rounds/round1/memo-1.md`，围绕第 7 节的推翻条件补检，用同一套 Skill 处理材料，读取同一个 Agent 定义形成 `rounds/round2/memo-2.md`，比较原判断、补检结果与更新理由，保留第一轮全部文件。

**两次边界更正，都是自己发现自己改的。**

第一次（11-26 23:40）：引文追溯捞出余明桂等《数字基础设施建设、公共算力供给与AI创新》（《经济研究》2026 年第 8 期）。该文摘要含「AI 创新质量」而关键词不含「创新质量」，主题检索未命中。据此把边界由「没人做质量」改为「**均值已做、分布未做**」。

第二次（11-27 00:50）：召回补正核查捞出谢璇等《算力基础设施如何影响企业数字技术创新?》（《经济与管理研究》2026 年第 7 期）。该文与谷城同政策冲击、同样本窗口、同方法，且报告「大企业数量、小企业质量」的异质性——**按规模分组的质量差异已有人做**。边界再收窄为「**分组均值已做、连续分布未做**」，并把设计改为「质量鸿沟与数量鸿沟并列，检验两者是否同向」。

两处漏检均未事后修饰：T0 的 9 条清单、第一轮全部文件、`memo-1.md` 一律保持原样，更正以带时间戳的补记方式追加。

现有 8 篇归档：全文精读 4 篇、仅摘要 4 篇；重复归档 0 条；反向链接 8 对中 6 对为文件级与面板双重校验、2 对仅文件级（面板未再复核，已如实标注）。

**第四篇全文（11-27 00:24）**：余明桂等（2026）24 页全文核对完毕，同样无任何分布度量——「离散」「变异系数」「基尼」「分位」「鸿沟」「分布」「极化」「集中度」出现次数均为 0，「差距」3 次全为无关语境。其质量口径是**专利知识宽度**（IPC 分类加权），企业—年份用均值与中位数两种方式汇总，两种都是中心位置，说明作者知道分布形状会影响结论却没测离散度。

**Q2 全量复核（00:26）**：208 条已全部取得（时间切片绕开翻页验证码，8 片合计 208、去重后仍 208、零重复），按领域分组为政策理论类 131、经济管理实证 46、其他 18、计算机与工程 7 等。46 条中又捞出 2 篇做**质量构成占比**（策略性 vs 实质性）的：软科学（2026-04）「结构性矫正」、管理学报（2024-07）「实质性绿色创新偏好」，均限绿色口径。据此边界做第四层细分：质量均值已做、构成占比已做、分组均值已做、**企业间离散度仍未做**。

**第三篇全文（11-27 00:16）换来的两条硬证据**：谢璇等（2026）的质量指标是「专利被引次数总量 + 1 取对数」，不是比率，被引随专利数累积，质量与数量高度相关，被引窗口亦未交代；更要紧的是它在描述性统计里已写明「创新活动呈现较强的企业间分化特征」（均值 83.59、标准差 1 149.09），却只把分化当样本特征，全文「离散」「变异系数」「基尼」「分位」「差距」「鸿沟」出现次数均为 0。**分化被看见，但没被当作结果变量**——这比「检索未见」是更硬的立足点。该文另有识别短板：只有个体与年份固定效应，缺城市固定效应，标准误处理未交代，与谷城的三重固定效应 + 城市聚类形成对照。
