# 输入

1. `rounds/roundN/search-log.md` 的候选表：确定本轮要读的序号、题名、全文状态。
2. 论文原始件：
   - 有全文：`sources/<第一作者><年份>.pdf`（副本来自 Zotero storage 或知网下载）。
   - 无全文：只用知网题录页的摘要与关键词。
3. 附录：`sources/<第一作者><年份>-附录.docx`，仅在主文出现「见附录」「附表 X」且该结论进入笔记时读取。

# 处理规则

## 阅读范围必须可核验

- 笔记开头写明：`阅读范围：主文 p.X–p.Y；附录 §X；未读 p.Z–p.W（原因）`。
- 全文精读须覆盖四段：问题与文献定位、数据与样本、方法与识别策略、结果与稳健性、局限。
- 只读摘要的论文，笔记开头标 `阅读范围：仅摘要`，且全文禁止出现摘要中不存在的信息。

## 六类字段的判断标准

1. **问题**：作者声称要回答什么，与哪支文献对话。区分「作者自述的贡献」与「可从方法推断的实际贡献」。
2. **材料或样本**：样本区间、层级（城市/企业/个体）、观测数、数据来源。缺一项就写「未说明」。
3. **方法或识别策略**（实证）：计量模型、处理变量、被解释变量、固定效应、识别假设（平行趋势/外生冲击/工具变量排他性）。
   **方法或假设**（理论）：模型设定、关键假设、比较静态。
4. **发现**：主效应方向与量级、机制检验、异质性结论。每条结论后加定位 `(p.12, 表 3 第 2 列)`。
5. **局限**：作者自陈的局限，加上你能从识别策略推出的局限（两者分开列）。
6. **可核实性**：哪些结论能被他文或数据核实，哪些只能依赖作者表述。

## 定位标注

- 页码用 PDF 物理页，另注期刊页码（若有）。
- 表图写作 `表 X 第 Y 列` / `图 X`，并在材料文件里附该表的关键数值行。

## 禁止事项

- 不得用摘要推断样本量、系数符号或显著性。
- 不得把「作者引用他人的结论」写成「本文发现」。
- 不得跨论文补全：某篇没做的事，不写成「该文未考虑，因此本文贡献是……」

# 输出

## 1. `materials/<第一作者><年份>.md`

交给下游的原料，只放会用到的内容：

```
# <题名>
- 版本：期刊版 / 网络首发 / 工作稿；DOI
- 阅读范围：主文 p.X–Y；附录 §X
- 变量定义：（被解释变量、核心解释变量、控制变量，各一行）
- 关键表：表 3 主回归（系数 0.0xx，t= x.xx，N=xxxx）
- 关键段落摘录：（原文短句，注明页码）
```

## 2. `vault/10-论文笔记/<第一作者><年份>-<短题>.md`

六节固定：`## 问题`、`## 材料与样本`、`## 方法与识别`、`## 发现`、`## 局限`、`## 与本研究的关系`。
每节末尾的定位标注不可省略。文件尾加 `tags: [算力, 创新]` 与 `来源: [[<期刊><年份>]]`。

## 3. 交接

笔记完成后不自行改索引，交归档 Skill 处理链接与去重。
